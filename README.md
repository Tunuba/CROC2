# CROC2

Descompilacion de *Croc 2* (PlayStation, 2001, Argonaut Software / Fox Interactive). A
diferencia de Bomberman Hero y de Croc 1, nadie ha tocado el ejecutable todavia: solo existen
herramientas de terceros para extraer texturas, WAD y sonido, nunca el codigo. Ver
`notas\TRASPASO.md` para el estado completo y los bloqueos.

## Carpetas

- `herramientas\` herramientas de terceros para formatos de Croc 2 (no van al repo): PS1-Argonaut-Reverse
  (extraccion de WAD/DAT), Croc2ExplorerWV (explorador de WAD), Croc-2-mods (documentacion y hashes).
- `notas\TRASPASO.md` por donde seguir; trae la comparacion con Bomberman Hero y Croc 1, y los
  dos bloqueos pendientes (disco y decision de repositorio).
- `disco\`, `extraido\`, `estados\`, `decomp\` se llenan cuando Meme ponga el disco; no van al repo.
- `scripts\` herramientas propias, vacio por ahora.
